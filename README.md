# Hazelink, Allê Ebrahim VENDAS

Página profissional estática em HTML, CSS e JavaScript para o Hazelink de Allê Ebrahim VENDAS.

## Estrutura

- `index.html`, estrutura sem estilos embutidos
- `css/styles.css`, direção visual, responsividade e acabamento
- `js/script.js`, dados dos links, ícones e interações
- `assets/alle-ebrahim.png`, foto usada no perfil
- `assets/cafe-background.png`, imagem de fundo criada para a página

Abra `index.html` no navegador para visualizar.
